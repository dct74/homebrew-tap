# Homebrew tap

```bash
brew install --cask dct74/tap/cliphistory
```

| Cask | Description |
|---|---|
| `cliphistory` | Menu bar clipboard history (macOS 14+) |

Upgrade: `brew upgrade --cask cliphistory`
Uninstall: `brew uninstall --cask cliphistory` (add `--zap` to drop the history and preferences too)
